# 해양 수온·염분 예측기

위도·경도를 입력하거나 지도를 클릭하면, 한반도 주변 해역의 **월별·수심별 수온과 염분**을 추정해 보여 주는 정적 웹페이지입니다.
서버·빌드 없이 `index.html` 하나로 동작하며 GitHub Pages에 바로 올릴 수 있습니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 화면 + 지도(Leaflet) + 예측 로직 전부 |
| `data.js` | 관측 데이터(207개 정점, 4,145건)를 변환한 파일 |
| `build_data.py` | 엑셀 → `data.js` 변환 스크립트 (데이터를 갱신할 때만 필요) |

## GitHub Pages로 올리기

1. 새 저장소를 만들고 `index.html`, `data.js`, `build_data.py`, `README.md`를 올립니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 저장합니다.
3. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 주소로 열립니다.

## 랜딩 페이지에서 연결하기

- 버튼/링크로 연결: 위 GitHub Pages 주소를 그대로 걸면 됩니다.
- 특정 지점으로 바로 열기: `?lat=35.9&lon=125.8&m=8&z=0` 처럼 주소 뒤에 붙이면 해당 위치·월(1~12)·수심(0/10/20/30/50)으로 열립니다.
- 랜딩 페이지 안에 넣기: `<iframe src="https://<계정>.github.io/<저장소>/" width="100%" height="720" style="border:0"></iframe>`

## 예측 방법

- 선택한 월·수심에 관측값이 있는 정점 중 **가장 가까운 5곳**을 거리 제곱의 역수로 가중 평균(IDW)합니다.
- 관측이 없는 달(7월, 11~12월 등)은 앞뒤 달 예측값을 직선으로 보간합니다(연말~연초는 순환).
- 신뢰도: 가장 가까운 정점이 50 km 이내면 높음, 100 km 이내면 보통, 그 이상은 낮음, 200 km 넘으면 예측하지 않습니다. 보간한 달은 최대 '보통'(간격이 3개월 이상이면 '낮음')입니다.
- 정점 하나를 빼고 맞혀 보는 교차검증 평균오차: 수온 약 0.9 °C, 염분 약 0.17 psu (정점 간격 20~40 km 이내 기준, 60 km 이상은 검증되지 않음).

## 한계

- 2026년 1~10월 관측 한 해치만 사용합니다. 연도별 변동, 일 단위 변화, 조석, 연안 담수 영향은 반영하지 않습니다.
- 1·3·5·9월은 관측 정점이 적어(6~26개) 멀리 떨어진 곳은 신뢰도가 낮습니다.
- 육지·항만 안쪽 좌표를 걸러내지 않습니다.
- 엑셀의 '모델 평균/최저/최고' 열은 영역 전체 통계라 위치별 예측에 쓰지 않았습니다.
- 연구·학습용 추정값이며 항해·조업 등 안전 판단에는 사용하지 마세요.

# 미래 해양 수온·염분 예측기

위도·경도와 목표 미래 시점(연도·월·일)을 입력하거나 지도를 클릭하면, 한반도 주변 해역의 **미래 수온·염분과 2026년 기준 관측 대비 변화량($\Delta T, \Delta S$), 예측 불확실성($\pm$ 오차범위)**을 추정해 보여 주는 정적 웹페이지입니다.
서버·빌드 없이 `index.html`과 `data.js`만으로 동작하며 GitHub Pages와 Render Static Site에 바로 배포할 수 있습니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 지도(Leaflet) + 공간 보간(IDW) + 계절 조화 모델 + 미래 추세 예측 UI 전부 |
| `data.js` | 2026년 KODC 정선해양 관측 데이터(207개 정점, 4,145건) |
| `build_data.py` | 엑셀 → `data.js` 변환 스크립트 (관측 데이터 갱신 시 사용) |
| `render.yaml` | Render Static Site 배포 설정 파일 |

## 랜딩 페이지(lander) 및 URL 파라미터 연동

- 기본 주소: `https://<계정>.github.io/<저장소>/` 또는 `https://<서비스명>.onrender.com/`
- 특정 좌표·미래 시점으로 바로 열기:
  `?lat=35.9&lon=125.8&y=2028&m=8&d=15&z=0&sc=standard`
  - `y`: 목표 연도 (`2026`~`2040`)
  - `m`: 월 (`1`~`12`)
  - `d`: 일 (`1`~`31`, 생략 시 관측일/15일 자동 적용)
  - `z`: 수심 (`0`, `10`, `20`, `30`, `50`)
  - `sc`: 시나리오 (`standard`, `accelerated`, `seasonal`, `custom`)

## 미래 예측 방법

1. **공간 보간 (IDW):** 기준 연도(2026년) 관측에서 반경 200 km 이내 가장 가까운 5개 정점을 거리 제곱의 역수로 가중 평균합니다.
2. **계절 조화 모델 (Harmonic + Residual):** 관측된 날짜(DOY)를 이용해 1차 푸리에 급수($c_0 + c_1\cos\omega t + s_1\sin\omega t$)로 연주기 계절 곡선을 적합하고, 관측 지점의 잔차를 순환 보간하여 미관측 월(7월, 11~12월 등)의 계절 변동을 추정합니다.
3. **미래 추세 투영 및 수심 감쇠:** 국립수산과학원(NIFS) 장기 관측 추세를 참고한 해역별 표층 수온 상승률(동해 $+0.038\,^\circ\text{C/년}$, 남해·동중국해 $+0.032\,^\circ\text{C/년}$, 서해 $+0.028\,^\circ\text{C/년}$)에 수심 감쇠 계수($e^{-z/85}$)를 곱해 경과 연수($\Delta t$)만큼 반영합니다.
4. **불확실성 산출:** 공간 보간 교차검증 오차(수온 약 $0.9\,^\circ\text{C}$, 염분 약 $0.17\,\text{psu}$)에 계절 보간 오차 및 미래 연변동 불확실성을 합성해 $\pm 1\sigma$ 예측 범위를 표시합니다.

## 한계 및 주의사항

- 2026년 단일 연도 관측을 기준선으로 사용하므로 엘니뇨·라니냐, 태풍, 집중호우로 인한 연안 담수 유입 등 단기 이상기후 변동은 반영하지 않습니다.
- 5년 이상 장기 예측은 평균 기후 추세 연장값이므로 불확실성이 큽니다.
- 연구·학습용 추정치이며 항해·조업 등 안전 판단에는 사용하지 마세요.
